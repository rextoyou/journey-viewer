Journey Viewer

Open your For the Journey save file, add your screenshots, and read your adventure back.
Where do I find my files?

Nothing is uploaded anywhere. This page reads your files inside your own browser and forgets them when you close it.

  1. Your save file for one character (the one this page needs). Copy this path, then paste it into the address bar of a Windows Explorer window and press Enter. Replace the capital words with your own account, realm and character names:
    C:\Program Files (x86)\World of Warcraft\_classic_beta_\WTF\Account\ACCOUNTNAME\REALMNAME\CHARACTERNAME\SavedVariables\ForTheJourney.lua
  2. Optional: the account file. It holds a backup of every character you have played with the addon, so the character list in the top corner fills up:
    C:\Program Files (x86)\World of Warcraft\_classic_beta_\WTF\Account\ACCOUNTNAME\SavedVariables\ForTheJourney.lua
  3. Your screenshots:
    C:\Program Files (x86)\World of Warcraft\_classic_beta_\Screenshots
    Use "Add Screenshots folder" and pick that folder, or drag the pictures onto this page.
  4. The game only writes the save file when you log out, quit, or type /reload. If something you did today is missing, do one of those and open the file again.
  5. Screenshots are matched to milestones by the time in their file names (WoWScrnShot_MMDDYY_HHMMSS). Milestones from before addon version 1.33 have no exact time, so they are matched to the closest minute where possible.
